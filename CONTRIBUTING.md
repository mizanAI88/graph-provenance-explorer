# Contributing

Thank you for looking at this repository. It is small on purpose; please keep
it that way.

## Ground rules

- No datasets, no downloaded files, no model weights in the repository. The
  corpus is authored fiction and must stay obviously fictional: invented terms,
  no real drug names, no real guidelines. `tools/check_corpus.py` must pass.
- No numbers in the README or docs that a script in this repository did not
  compute on the shipped fixture, and every such number is labelled as
  computed on the fixture.
- No network access in tests, `make smoke` or `make demo`.
- No new dependencies beyond networkx, numpy and pyyaml without a stated reason.
- No em dashes and no marketing adjectives in prose.

## Workflow

```
pip install -e .
pip install pytest
python -m pytest -q
python -m graph_provenance_explorer smoke
python -m graph_provenance_explorer demo
python tools/check_corpus.py
python tools/render_figure.py
```

Before opening a pull request: tests pass on Python 3.10, 3.11 and 3.12 (the
CI matrix), the committed `examples/output` was regenerated by `demo` if
anything affecting it changed, and `docs/evaluation.md` carries the new
summary line if the test count changed.

## Adding to the corpus

Add a `DOC-M1.md` with front matter, the fiction blockquote, and `[p1]`,
`[p2]`, ... passages between 150 and 300 words in total. Add edges to
`relations.yaml` with a type from the five allowed and
`provenance: authored-v1`. Add questions to `examples/questions/v1.jsonl`
with gold passage ids that resolve. Then run `demo` and commit the regenerated
outputs, and rerun `tools/check_corpus.py` to refresh `FIXTURE.md`.

## Reporting problems

Open an issue on the repository with the command you ran, its full output,
and your Python version.
